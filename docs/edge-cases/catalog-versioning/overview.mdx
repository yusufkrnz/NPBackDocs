# Catalog / Component Versiyonlama

## EDGE-CASE-018: Eski Render Ağacı, Yeni Component API'siyle Uyumsuz Kalır

**Risk: Orta-Yüksek.** Bir dashboard/render ağacı persist edilirken hangi `catalog_version` ile üretildiği hiç kaydedilmiyor/kontrol edilmiyor. Frontend'in kullandığı kütüphane (örn. Recharts) major sürüm atlarsa (`^2.8.0` → `^2.10.0`), eski ağaçtaki bir prop'un (örn. `LineChart`'ın custom `dot` imzası) anlamı değişmiş olabilir — versiyon kontrolü/migration adımı olmadan bu sessizce kırılır.

render(tree)
