# API Reference

Bu sitede elle yazılmış bir "endpoint listesi" sayfası **yok** — kasıtlı olarak. FastAPI, `routers/`'daki route tanımlarından ve `schemas/`'daki Pydantic modellerinden OpenAPI şemasını otomatik üretir. Elle yazılan bir referans, kod değiştikçe kaçınılmaz olarak eskir (drift); otomatik üretilen asla eskimez.

## Canlı referans nerede

| Ortam | Swagger UI | ReDoc |
|---|---|---|
| Local | `http://localhost:8000/docs` | `http://localhost:8000/redoc` |

Servis ayakta olduğu sürece bu adresler her zaman o an deploy edilmiş koda birebir uyar.
